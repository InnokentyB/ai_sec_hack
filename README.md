## MVP

Одна глубина: владелец → оркестратор → исполнитель. Одно действие:
доставка конкретного synthetic документа конкретному получателю в локальный inbox.
Права сужаются, исходный лимит общий для всех детей. Подмена, отзыв, expiry и replay
проверяются перед dispatch. Неизвестный результат не выдаётся за успех.
Журнал и экспорт подписаны; verifier получает доверенные fingerprints отдельно.

Никаких реальных подписей договоров, платежей, внешних отправок или live provider в MVP.
Блокчейн — необязательное будущее закрепление контрольных хешей, не реализован.

## Разработка

Все installs/builds/tests/browser automation на Tower только внутри Docker.
Рассмотренных Dockerfile/Compose и проверенных runtime-команд пока нет: runnable
приложение ещё не создано. Сначала подтвердить Input/Surface gate, затем создать
контейнерную инфраструктуру и исполняемые RED-сценарии, после — реализацию и UAT.
Продуктовые секреты, ключи, базы и runtime artifacts не коммитить.

TDPD / Test-Driven Product Development — оригинальный метод Иннокентия Бодрова.
Лицензия пока не выбрана. Конкурсная подача и юридическая значимость не заявляются.
